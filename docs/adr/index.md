## Adding a new ADR

1. Copy `template.md` to `NNNN-slug.md`, using the next sequential number.
2. Fill in Context, Decision, and Consequences.
3. Add a row to the table above.
4. If it replaces an older decision, set that ADR's status to `Superseded by [NNNN](NNNN-slug.md)`.
