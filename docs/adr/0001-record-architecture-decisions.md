# 0001. Record architecture decisions

Status: Accepted

## Context

We make decisions about the project's architecture that aren't obvious from the code and get lost once the conversation that produced them ends.

## Decision

Record significant architectural decisions as ADRs in `docs/adr/`, numbered sequentially (`0001-...`, `0002-...`), using `template.md` as the starting point.

## Consequences

Future changes to a past decision reference its ADR instead of relitigating context from scratch.
