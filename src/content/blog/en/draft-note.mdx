If you can read this in a production build, draft filtering is broken.

I've been building software for years and never kept a blog. This is me fixing that.

## Why now

Writing forces clarity. If I can't explain a thing simply, I probably don't
understand it yet — so this is as much for me as for anyone reading.

## The stack

This blog runs on **Astro** with content collections and MDX, so every post is
just a file with frontmatter:

- Markdown for the prose
- Components when a plain paragraph won't do
- Two languages, one shared slug per translation pair
