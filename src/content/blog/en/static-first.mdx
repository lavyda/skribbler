The fastest component is the one that never hydrates.

## Lean on the platform

Modern CSS does a lot that used to demand a script — container queries, `:has()`,
scroll-driven animation, `light-dark()`:

```css
.card {
  container-type: inline-size;
}
```

> Reach for JavaScript when the platform genuinely can't express the idea —
> not by default.

That's the whole philosophy, and it keeps pages fast and durable.
