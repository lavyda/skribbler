Najrýchlejší komponent je ten, ktorý sa nikdy nehydratuje.

## Spoľahni sa na platformu

Moderné CSS zvládne veľa, čo kedysi vyžadovalo skript — kontajnerové dopyty,
`:has()`, animácie riadené scrollom, `light-dark()`:

```css
.card {
  container-type: inline-size;
}
```

> Po JavaScripte siahni vtedy, keď to platforma naozaj nevie vyjadriť —
> nie automaticky.

To je celá filozofia a vďaka nej sú stránky rýchle a odolné.
